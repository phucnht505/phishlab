# PhishLab Analytics Dashboard

Cài dependency từ thư mục gốc:

```powershell
python -m pip install -r .\analytics\requirements.txt
streamlit run .\dashboard\app.py
```

Tải Results CSV (bắt buộc), Raw Events CSV (khuyến nghị) và Quiz summary CSV (tùy chọn; chỉ gồm tổng số người bắt đầu, hoàn thành và điểm trung bình, không có thông tin người tham gia).
